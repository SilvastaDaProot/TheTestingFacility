Featured Experiments

The projects currently taking up the most rack space and brain space.

Proxmox Cluster

Two servers + a Raspberry Pi quorum device. The backbone of the facility — everything else runs on top of this.

  • Game Hosting — dedicated game servers
  • Storage Host — reliable storage solutions
  • VPN Hosting — secure VPN services
  • DNS / AdBlock — network-wide ad blocking

3D Printing

Custom objects, functional parts, and the occasional benchy. The only machine in the facility that produces physical evidence.

  • Custom parts — designed, printed, iterated
  • Functional prints — things that actually get used
  • Calibration — the eternal quest for perfect first layers

Clicksee Tracker

A self-hosted link, pixel & conversion tracker. Full visitor fingerprinting, bot detection, and AI-generated overviews.

  • Status: ● Live
  • Stack: Flask + SQLite + Docker
  • Extra: AI overviews via local Ollama

Meshtastic Mesh

LoRa-based off-grid mesh networking. The web client runs in the Docker lab; the radios handle the rest.

  • Status: ● Live
  • Client: Meshtastic Web on :4488
  • Network: no cell towers required

Element Lab

"Matter" — a combine-everything sandbox game with an AI oracle endpoint. Built as a fun side project, currently parked.

  • Status: ● Parked
  • Containers: oracle + game

Mr Handy Bot

A Discord moderation bot: warnings, mod logs, reaction roles, auto voice channels. Dev container, off-duty for now.

  • Status: ● Parked
  • Stack: Node + Prisma + Docker
